# PROJETOS

Pasta de trabalho dos projetos do Helder (SICAD).

Este é o espaço onde vivem os nossos projetos dentro do repositório. Tudo o que
for colocado aqui fica **versionado em git** e pode ser sincronizado para o teu
computador com `git pull`.

## Relação com o OneDrive

No teu computador, esta pasta corresponde a:

```
C:\Users\HP\OneDrive - Serviço de Intervenção nos Comportamentos Aditivos e nas Dependências -SICAD\NEW\HELDER\PROJETOS
```

> **Nota importante:** o Claude Code, quando corre no ambiente remoto (na web),
> **não tem acesso direto** à pasta do OneDrive — trabalha dentro deste
> repositório git. Para levar o trabalho para o teu computador (e para o
> OneDrive), faz `git pull` na tua máquina. Se, em vez disso, correres o Claude
> Code **localmente** no Windows, aí sim ele consegue trabalhar diretamente na
> pasta do OneDrive.

## Organização

Cada projeto tem a sua própria subpasta:

```
PROJETOS/
  <nome-do-projeto>/
    README.md        # descrição, objetivos e estado do projeto
    ...              # ficheiros do projeto
```
